# Creative kraft pack — Espresso Escape

Casa Rústico paper-craft sprites for the café runner.

**Brand lock:** cream `#F7F3EC`, kraft `#A47C59`, dark kraft `#8D6C4F`.
Highland coffee / café identity. Handmade technique (paper layers, cardboard,
sackcloth, sticker chrome) — not a third-party reskin.

## Drop-in names

Replace any file in this folder with a Creative PNG of the same name:

| File | Role |
|---|---|
| `runner.png` | Player (roast bean runner) |
| `grinder.png` | Low hop hazard |
| `portafilter.png` | Tall hop hazard |
| `steam.png` | Stay-low hanging steam |
| `bean.png` | Honey bean pickup |
| `cafe-bg.png` | Café stage backdrop |
| `menu-panel.png` | Title / pause / Best Run chrome |

The game `require()`s these exact paths. No code change needed for a PNG swap.
